Scope: the home page (`src/pages/index.astro`) and the Bench page, which inherits the world. Visitor mode: **Persuade**.

Audience: Claude Code users, 3D artists / game devs, three.js devs. Job: be convinced kiln's objects are worth trusting, then install it. Constraints: every number from `src/content/site.json` (bench / README); no paid service; no testimonials.

## Direction contract

Owner-pinned on 2026-10-08 ("La forge, cinématique", no comps, code-led), replacing the studio direction (seed e3de59dd) after the owner judged it dull and not a 2026 site.

THESIS: kiln is a forge — a photo goes in, an object comes out of the fire, measured. The page is one continuous WebGL scene driven by the scroll, not a document with a 3D frame in it. It refuses the static evidence page and the dark SaaS hero alike.

OWN-WORLD: night-black ground (#0b0908) lit only by the forge: ember orange (#ff5a14) and molten yellow (#ffb547) as light, kiln's flame (#d67e2c) as the brand, slate blue (#343c62) as the forge's stone; film grain fixed over everything; Clash Display set huge, Geist for text, Geist Mono for measures; pill controls, a floating pill nav; bloom on emissive things only.

STORY: the forge burns → the camera falls into it → an object rises out of the fire and is graded against the real one (lantern, ammo box, chair) → the session's own files, pinned and panned → fifteen lanterns flip by as you scroll → kiln's creatures move live in WebGL → ÷34 → install.
